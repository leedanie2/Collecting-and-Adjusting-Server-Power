# Collecting and Adjusting Server Power

Work done during the 2026 Future Computing Summer Internship at the National Security Agency. Project focused on collecting server CPU power and smoothing large power swings from bulk-synchronous jobs in HPC clusters. 'Code' contains our live dashboard stack, power smoothing mechanisms, benchmarks, evaluation, and other miscellaneous models. 'Deliverables' has our technical report, slide decks that we presented to NSA executives, and a poster presented at research conferences. For questions, email leedanie2@grinnell.edu.
